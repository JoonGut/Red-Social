# Red Social

Proyecto de **creación de una red social** desarrollado como aplicación web full-stack.  
Este repositorio contiene el código fuente de una red social básica con funcionalidades como registro de usuarios, inicio de sesión y publicación de contenido.

El proyecto está pensado como base de aprendizaje o punto de partida para el desarrollo de una plataforma social propia.

---

##  Características

-  Registro de usuarios  
-  Inicio y cierre de sesión  
-  Creación y visualización de publicaciones  
-  Gestión básica de usuarios  
-  Separación entre frontend y backend
